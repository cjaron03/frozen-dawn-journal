Section 1: Page map & the gate

Five routes, not fifteen. Every "card type" you described, issues, growth, stunts, the break, is one content collection with a kind field, not a separate section. The gate is a single boundary, crossed once.

Routes
Public layer: spoiler-safe, indexable
/The hook. What Frozen Dawn is, the strongest screenshot, two doors: the timeline and the Architect.
/timelineThe spine. Every entry as a card, chronological, filterable by kind. The June gap renders as a real gap.
/timeline/[slug]One entry, full narrative. Git facts in a sidebar; your prose in the body.
/colophonHow this site is built. The sync script, the data snapshot, the stack. Short.
▲ Spoiler gate: crossed once, remembered

One interstitial before /architect. Choice stored in localStorage so it never asks twice. This is a courtesy, not security. The content ships in the HTML and anyone can view-source. That's the right tradeoff for spoilers, and the gate copy should be honest about being a curtain rather than a lock.

Gated layer: the brainchild
/architectThe hub. What the Architect is, why it exists, the three forms, and the design problem it solves.
/architect/mindThe live decision sim. Seven actions, nineteen inputs, exact port of your Java.
One collection · six kinds
releaseAnchored to a real git tag.
milestoneA checkpoint you declare, not a tag.
struggleWhere it broke. The honest ones.
breakthroughGrowth: when something clicked.
hiatusThe break. Scaffolded from real commit silence.
deepdiveTechnical. Lives behind the gate.
All six are the same Markdown collection with one schema. A card renders differently by kind; the timeline filters on it; the gate hides only deepdive. Adding a seventh kind later is one schema line and one CSS block, not a new page type.
